# Simulation

`Simulation` is where you open a project, get its objects, and control its run.
It owns the isolated SWMM project, files, lifecycle, collections, and current
generation. See [Package metadata](package-metadata.md) for package and embedded
solver identities, or the [user guide](../user-guide.md) for lifecycle and
continuation examples.
