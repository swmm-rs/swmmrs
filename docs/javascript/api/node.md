# Node

`Node` provides declaration edits, current results, runtime forcings, and
statistics for one node. Obtain a handle from `simulation.nodes.get(id)`.

See the user guide for [configuration workflows](../guides/configure-model.md#configure-node-kinds),
[runtime forcings](../guides/runtime-forcings.md), and
[collecting results and statistics](../guides/collect-results.md).
